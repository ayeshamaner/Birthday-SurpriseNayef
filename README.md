# Birthday Surprise — GitHub Pages Ready

1. Open `script.js` and change `PASSWORD="1401"` and `NAME="Nayuuu"`.
2. Edit the birthday letter, story, balloon messages and wishes in `index.html`/`script.js`.
3. Add photos as `photos/photo1.jpg` through `photos/photo5.jpg`.
4. Add music as `music/music.mp3`.
5. Create a GitHub repository called `birthday-surprise`.
6. Upload everything in this folder, including the `photos` and `music` folders.
7. GitHub: Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
8. Your link will look like `https://YOUR-USERNAME.github.io/birthday-surprise/`.

Privacy: the password is a surprise/access gate, not strong security. A normal GitHub Pages site is public, so do not put sensitive information in the repository. Someone technically skilled could inspect the JavaScript and bypass the gate.

Music: browsers may block autoplay; the site attempts to start music after user interaction and has a music button.
